# Анализ проекта VideoVault и рекомендации по улучшению

## Обзор проекта

Проект представляет собой одностраничный лендинг [`index.html`](../index.html) для сервиса бесплатных ресурсов видеомонтажа (шаблоны, футажи, музыка, LUTs). Вся разметка, стили и логика находятся в одном HTML-файле.

**Текущий стек:**
- HTML5 + Tailwind CSS через CDN (`cdn.tailwindcss.com`) — development-сборка
- Font Awesome 6.4.0 (CDN), Google Fonts: Montserrat + Inter
- Ванильный JavaScript инлайн (мобильное меню, тосты, «заглушки» скачивания)

## 2. Производительность

| # | Проблема | Рекомендация |
|---|----------|--------------|
| 2.1 | Tailwind Play CDN (`cdn.tailwindcss.com`) — это dev-версия: ~300 КБ JS, предупреждение в консоли, медленная первая отрисовка. Для продакшена непригодна | Собрать статический CSS через Tailwind CLI (или Vite + Tailwind) и подключать только готовый `style.css` |
| 2.2 | Три фоновых «орба» с `filter: blur(90px)` + `animate-pulse` — тяжёлая нагрузка на GPU, особенно на мобильных | Уменьшить радиус блюра, убрать анимацию у дальних орбов, отключить при `prefers-reduced-motion` |
| 2.3 | Ресурсы CDN (шрифты, иконки, Tailwind) блокируют рендеринг, нет SRI-атрибутов | Добавить `defer`/`async` где возможно, `integrity`/`crossorigin` к CDN-ресурсам, `preconnect` уже есть для шрифтов |
| 2.4 | У продуктов нет реальных превью — только CSS-градиенты. Это снижает доверие и конверсию | Добавить настоящие изображения-превью (WebP, `loading="lazy"`, `width`/`height`) |
| 2.5 | Отсутствуют `robots.txt`, `sitemap.xml`, favicon | Создать базовые SEO-файлы и иконку сайта |

## 3. Архитектура и качество кода

| # | Проблема | Рекомендация |
|---|----------|--------------|
| 3.1 | Всё в одном файле: разметка + стили + логика. Сложно поддерживать и масштабировать | Разделить на: `index.html`, `css/style.css`, `js/main.js`, `js/data.js` |
| 3.2 | 4 карточки товаров и 4 карточки категорий продублированы копипастой | Перевести на data-driven рендеринг: массив данных в `js/data.js` → генерация карточек в JS (или сборка через шаблонизатор) |
| 3.3 | Конфиг `darkMode: 'class'` объявлен, но переключателя темы нет, сайт всегда тёмный | Либо добавить переключатель темы, либо удалить лишнюю конфигурацию |
| 3.4 | Цвета заданы двумя способами: через `tailwind.config` и хардкодом hex в `<style>` | Унифицировать через единую палитру (Tailwind theme + CSS-переменные) |
| 3.5 | Магические числа в тексте («2,450+ файлов», «840+») захардкожены | Вынести в данные и подсчитывать автоматически |
| 3.6 | Статические цифры «Обновление 2026» и «© 2026» быстро устаревают | Генерировать год через JS или обновлять контент по дате |
| 3.7 | Нет системы сборки и контроля версий структуры | (Опционально) подключить Vite + Tailwind для сборки, минификации и livereload |

## 4. Доступность (A11y)

| # | Проблема | Рекомендация |
|---|----------|--------------|
| 4.1 | Кнопка мобильного меню не имеет `aria-expanded` / `aria-controls` | Добавить ARIA-атрибуты и обновлять их при открытии/закрытии |
| 4.2 | Тост-уведомление не озвучивается скринридерами | Добавить `role="status"` / `aria-live="polite"` |
| 4.3 | Декоративные иконки FontAwesome не помечены `aria-hidden="true"` | Проставить `aria-hidden` на все декоративные иконки |
| 4.4 | Меню не закрывается по `Escape` и по клику вне области; при открытом меню страница прокручивается | Добавить обработку `Escape`, клик вне меню, блокировку скролла |
| 4.5 | Часть текста (`text-slate-500` на тёмном фоне) имеет низкий контраст | Проверить и повысить контраст (минимум 4.5:1) |
| 4.6 | Анимации (`animate-ping`, `animate-pulse`, hover-сдвиги) не отключаются для пользователей с vestibular-нарушениями | Добавить `@media (prefers-reduced-motion: reduce)` |
| 4.7 | Недостаточно видимых focus-состояний у интерактивных элементов | Обеспечить видимый фокус для всех кнопок и ссылок |

## 7. Безопасность

| # | Проблема | Рекомендация |
|---|----------|--------------|
| 7.1 | Нет SRI (`integrity`) на внешних скриптах и стилях | Добавить `integrity` + `crossorigin` к Google Fonts, FontAwesome, Tailwind |

## 8. Предлагаемая структура после рефакторинга

```text
videovault/
├── index.html            # разметка
├── css/
│   └── style.css         # собранный Tailwind + кастомные стили
├── js/
│   ├── main.js           # логика (меню, тосты, скачивание, фильтры)
│   └── data.js           # данные каталога и товаров
├── assets/
│   ├── img/              # превью продуктов (WebP, lazy)
│   ├── icons/            # favicon, og-image
│   └── downloads/        # реальные архивы
├── robots.txt
└── sitemap.xml
```
